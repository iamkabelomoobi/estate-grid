# @estate-grid/client

Shared generated client package for Estate Grid web and mobile apps.

It contains:

- GraphQL typed documents from `packages/client/schema.graphql`.
- A fetch-based OpenAPI SDK generated by Orval from `packages/client/openapi.json`.

Full module-by-module SDK usage is documented in [docs/sdk-usage.md](./docs/sdk-usage.md).

## Regenerate

```sh
npm run bootstrap --workspace @estate-grid/client
```

That exports the server GraphQL schema, exports the OpenAPI document, then regenerates both clients.

The GraphQL pipeline also generates typed operation documents for every top-level query and mutation in the schema.

To regenerate only the OpenAPI SDK:

```sh
npm run openapi:export --workspace @estate-grid/client
npm run generate:openapi --workspace @estate-grid/client
```

## OpenAPI Usage

For same-origin requests, no base URL setup is required.

```ts
import { getSession, signInWithEmail } from "@estate-grid/client";

const login = await signInWithEmail(
  {
    email: "user@example.com",
    password: "Passw0rd!123",
  },
  {
    credentials: "include",
  },
);

const session = await getSession({
  credentials: "include",
});
```

If the web app calls a different API origin, configure it once during startup:

```ts
import { setEstateGridApiBaseUrl } from "@estate-grid/client";

setEstateGridApiBaseUrl(process.env.NEXT_PUBLIC_API_URL ?? "");
```

## Mobile Usage

React Native needs an absolute API URL. Configure it once before calling SDK functions:

```ts
import {
  getSession,
  setEstateGridApiBaseUrl,
  signInWithEmail,
} from "@estate-grid/client";

setEstateGridApiBaseUrl("http://192.168.1.25:4000");

const login = await signInWithEmail({
  email: "user@example.com",
  password: "Passw0rd!123",
});

const session = await getSession();
```

For authenticated mobile requests, persist and pass the Better Auth cookie returned by the server. Browser web clients can use `credentials: "include"`; React Native generally needs explicit cookie handling.

## GraphQL Usage

```ts
import {
  QueryPropertiesDocument,
  requestGraphQL,
} from "@estate-grid/client";

const data = await requestGraphQL(
  QueryPropertiesDocument,
  {
    filter: {
      city: "Johannesburg",
      limit: 12,
    },
  },
  {
    credentials: "include",
  },
);

console.log(data.properties);
```

Generated operation names use `Query<FieldName>Document` and `Mutation<FieldName>Document`.
