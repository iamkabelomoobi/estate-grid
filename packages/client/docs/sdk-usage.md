# Estate Grid SDK Usage

`@estate-grid/client` exposes two SDK layers:

- OpenAPI SDK: fetch functions for HTTP/auth/transport endpoints generated by Orval.
- GraphQL SDK: typed operation documents for every top-level GraphQL query and mutation, plus a `requestGraphQL` helper.

## Setup

Install from the workspace:

```json
{
  "dependencies": {
    "@estate-grid/client": "*"
  }
}
```

Configure an API base URL when the app is not served from the same origin as the server.

```ts
import { setEstateGridApiBaseUrl } from "@estate-grid/client";

setEstateGridApiBaseUrl(process.env.NEXT_PUBLIC_API_URL ?? "");
```

React Native must use an absolute server URL:

```ts
import { setEstateGridApiBaseUrl } from "@estate-grid/client";

setEstateGridApiBaseUrl("http://192.168.1.25:4000");
```

## OpenAPI SDK

Use the OpenAPI SDK for auth and shared HTTP endpoints.

```ts
import { getSession, signInWithEmail, signOut } from "@estate-grid/client";

await signInWithEmail(
  {
    email: "user@example.com",
    password: "Passw0rd!123",
  },
  {
    credentials: "include",
  },
);

const session = await getSession({ credentials: "include" });

await signOut({
  method: "POST",
  credentials: "include",
});
```

Available OpenAPI functions include:

- `signUpWithEmail`
- `signInWithEmail`
- `signOut`
- `getSession`
- `executeGraphQL`
- `getOpenApiDocument`
- `renderDocs`

## GraphQL SDK

Use `requestGraphQL` with generated operation documents. Operation documents are regenerated from `schema.graphql`.

```ts
import {
  QueryPropertiesDocument,
  requestGraphQL,
} from "@estate-grid/client";

const data = await requestGraphQL(
  QueryPropertiesDocument,
  {
    filter: {
      city: "Johannesburg",
      limit: 12,
    },
  },
  {
    credentials: "include",
  },
);

console.log(data.properties);
```

Mutations follow the same pattern:

```ts
import {
  MutationCreateInquiryDocument,
  requestGraphQL,
} from "@estate-grid/client";

const data = await requestGraphQL(
  MutationCreateInquiryDocument,
  {
    propertyId: "property-id",
    input: {
      name: "Example User",
      email: "user@example.com",
      message: "I want to view this property.",
      source: "web",
    },
  },
  {
    credentials: "include",
  },
);

console.log(data.createInquiry?.id);
```

GraphQL errors throw `EstateGridGraphQLError`:

```ts
import {
  EstateGridGraphQLError,
  QueryMeDocument,
  requestGraphQL,
} from "@estate-grid/client";

try {
  const data = await requestGraphQL(QueryMeDocument, undefined, {
    credentials: "include",
  });
  console.log(data.me);
} catch (error) {
  if (error instanceof EstateGridGraphQLError) {
    console.error(error.errors);
  }
}
```

## Regeneration

Run the full client generation pipeline:

```sh
npm run bootstrap --workspace @estate-grid/client
```

Regenerate only the GraphQL operation documents and types:

```sh
npm run schema:export --workspace @estate-grid/client
npm run generate:graphql --workspace @estate-grid/client
```

Regenerate only the OpenAPI SDK:

```sh
npm run openapi:export --workspace @estate-grid/client
npm run generate:openapi --workspace @estate-grid/client
```
